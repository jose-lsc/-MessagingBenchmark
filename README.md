# Messaging Benchmark

Projeto desenvolvido para o Trabalho de Conclusão de Curso (TCC).

Objetivo:

Comparar RabbitMQ, Apache Kafka e Apache Pulsar utilizando uma aplicação desenvolvida em C#, analisando métricas como:

- Throughput
- Latência
- Uso de CPU
- Uso de Memória
- Confiabilidade

Tecnologias

- .NET 8
- Docker
- RabbitMQ
- Apache Kafka
- Apache Pulsar
